# Stich 0752 - Technical Reports & Fichas Técnicas

Sistema de gestión de informes técnicos y fichas técnicas para limpieza y desinfección de reservorios.

## Características

- Generación de informes técnicos en PDF
- Fichas técnicas de evaluación de actividades
- Importación de datos desde Excel/CSV
- Panel de administración web

## Tecnologías

- **Backend**: FastAPI + Python
- **Frontend**: React + Vite + TailwindCSS
- **PDF**: WeasyPrint + PyPDF
