### Task 2: Ajustar vite.config.js para Excalidraw

**Files:**
- Modify: `frontend/vite.config.js`

El paquete accede a `process.env.IS_PREACT` internamente. Sin el `define`, Vite elimina `process` y lanza un error en runtime.

**Step 1: Agregar `define` y actualizar `optimizeDeps`**

Reemplazar el contenido completo de `frontend/vite.config.js`:

```js
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import { resolve } from 'path'

export default defineConfig({
    plugins: [react()],
    define: {
        "process.env.IS_PREACT": JSON.stringify("false"),
    },
    resolve: {
        alias: {
            '@': resolve(__dirname, './src'),
            'framer-motion': resolve(__dirname, 'node_modules/framer-motion/dist/cjs/index.js')
        }
    },
    server: {
        proxy: {
            '/api/multi-sheet': {
                target: 'http://localhost:7861',
                changeOrigin: true,
            },
            '/api': {
                target: 'http://localhost:7860',
                changeOrigin: true
            }
        }
    },
    optimizeDeps: {
        include: ['lucide-react'],
        exclude: ['@excalidraw/excalidraw'],
    }
})
```

**Step 2: Verificar arranque**

```bash
npm run dev
```

Abrir `http://localhost:5173/` — confirmar que no hay errores de `process is not defined` en consola.

**Step 3: Commit**

```bash
git add frontend/vite.config.js
git commit -m "fix: configure vite for @excalidraw/excalidraw process.env"
```

### Task 4: Implementar el componente GioBoard

**Files:**
- Modify: `frontend/src/features/whiteboard/page.jsx`

**Step 1: Reemplazar page.jsx completo**

```jsx
import { Excalidraw, MainMenu } from '@excalidraw/excalidraw';
import '@excalidraw/excalidraw/index.css';
import './gioboard.css';

export default function GioBoardPage() {
    return (
        <div className="h-full w-full">
            <Excalidraw
                theme="dark"
                langCode="es-ES"
                initialData={{
                    appState: { theme: 'dark' },
                }}
                UIOptions={{
                    canvasActions: {
                        toggleTheme: false,
                        export: false,
                        loadScene: false,
                        saveAsImage: true,
                        clearCanvas: true,
                        changeViewBackgroundColor: false,
                    },
                }}
                renderTopRightUI={() => null}
            >
                <MainMenu>
                    <MainMenu.DefaultItems.SaveAsImage />
                    <MainMenu.DefaultItems.ClearCanvas />
                </MainMenu>
            </Excalidraw>
        </div>
    );
}
```

**Step 2: Navegar a `/whiteboard` y verificar**

- ✅ No hay toggle de tema

- ✅ Canvas ocupa todo el espacio disponible junto al sidebar

**Step 3: Commit**
